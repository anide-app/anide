# Object Storage Browser

Replaces: S3 Console, Cyberduck, Transmit, MinIO Console

Supports: AWS S3, Cloudflare R2, MinIO, Backblaze B2, DigitalOcean Spaces

## Storage

Each connection gets its own folder containing `config.md`. S3 has no queries concept
so there is no `queries/` subfolder.

```
.anide/s3/
  aws-production/
    config.md
  r2-assets/
    config.md
  minio-dev/
    config.md
```

## config.md format

Lives at `.anide/s3/<connection-name>/config.md`.

```markdown
---
name: "AWS Production"
type: s3
region: "{{env.AWS_REGION}}"
access_key_id: "{{env.AWS_ACCESS_KEY_ID}}"
secret_access_key: "{{env.AWS_SECRET_ACCESS_KEY}}"
endpoint: null   # null = AWS default; set for non-AWS providers
---
# AWS S3 production bucket

Main storage for user uploads and static assets.
```

**Cloudflare R2**

```yaml

name: "R2 Assets"
```

---

## Features

### Connection manager (sidebar panel)

- List connections from `.anide/s3/*.md`.
- "Test" pings the endpoint, lists buckets, shows latency.
- New connection wizard: provider preset picker (fills endpoint automatically) → credentials → test → save.

### Bucket browser

**Bucket list** (top level when connected)

- List all buckets: name, region, creation date.
- Click bucket → enter bucket browser for that bucket.

**Object browser** (inside a bucket)

- Breadcrumb navigation: `bucket-name / folder / subfolder /`
- Prefix-based "folder" simulation (S3 has no real folders — delimiter `/` creates the illusion).
- Two view modes: list view (name, size, last modified, storage class, content type) / grid view (thumbnail for images).
- Sort: by name, size, last modified.
- Search: filter visible objects by name prefix.
- Multi-select (checkbox) for bulk download or delete.

**Object actions** (right-click or action bar)

| Action | Description |
|---|---|
| Open | Preview in-app (see Preview section) |
| Download | Stream to local disk via dialog |
| Copy S3 URL | `s3://bucket/key` |
| Copy HTTPS URL | Public HTTPS URL (if bucket is public) |
| Generate Presigned URL | Configurable expiry (1h default) → copy to clipboard |
| Rename | Copy to new key + delete original |
| Move | Copy to different prefix/bucket + delete |
| Delete | Confirmation dialog; multi-object delete |
| View Metadata | Custom metadata, content-type, cache-control, ETag |
| Edit Metadata | Inline editor for user-defined metadata |

### Upload

- Drag and drop files or folders onto the browser pane.
- File picker button for single or multi-file select.
- Progress bar per file: bytes uploaded / total, transfer rate, estimated time.
- Concurrent uploads: up to 5 at once (configurable).
- Multipart upload for files > 100 MB (automatic, via `aws-sdk-s3`).
- On completion: refresh object list automatically.

### In-app preview

Triggered by clicking an object or choosing "Open":

| Content type | Preview |
|---|---|
| `image/*` | Full-res image in a lightbox panel |
| `text/*`, `application/json`, `application/yaml` | Syntax-highlighted code viewer |
| `application/pdf` | PDF rendered with browser PDF engine (via `<webview>` or `<iframe>`) |
| `video/*` | HTML5 `<video>` player |
| `audio/*` | HTML5 `<audio>` player |
| Everything else | "Download to preview" prompt |

Preview streams content directly from S3 — no intermediate temp file needed for images/text.

### Presigned URL generator

- Select object → "Generate Presigned URL".
- Expiry picker: 15m / 1h / 24h / 7d / custom.
- One-click copy to clipboard.
- URL shown with expiry timestamp.

### Bucket policy manager

- "Policy" tab on the bucket browser toolbar.
- Displays raw JSON bucket policy in CodeMirror editor.
- Edit + Save (calls `put_bucket_policy`).
- Warning banner if policy grants public access.

### Object metadata editor

- Key-value table of `x-amz-meta-*` headers + standard metadata.
- Editable fields: `Content-Type`, `Cache-Control`, `Content-Disposition`, custom `x-amz-meta-*`.
- Save updates via copy-object with new metadata (S3 has no in-place metadata update).

## Tauri commands (Rust)

### State

```rust
struct S3State {
    clients: Mutex<HashMap<String, aws_sdk_s3::Client>>,
}
```

### Commands

```rust
s3_list_connections(project_path: String) -> Result<Vec<ConnectionMeta>>
s3_save_connection(project_path: String, conn: S3ConnectionData) -> Result<()>
s3_delete_connection(project_path: String, name: String) -> Result<()>

s3_test_connection(project_path: String, conn: S3ConnectionData, env_context: EnvContext)
  -> Result<S3TestResult>   // { latency_ms, bucket_count }

s3_connect(project_path: String, connection_name: String, env_context: EnvContext)
  -> Result<()>   // builds Client, stores in S3State

s3_disconnect(project_path: String, connection_name: String) -> Result<()>

s3_list_buckets(project_path: String, connection_name: String)
  -> Result<Vec<BucketInfo>>   // { name, region, creation_date }

s3_list_objects(
    project_path: String,
    connection_name: String,
    bucket: String,
    prefix: String,          // current "folder" prefix
    delimiter: String,       // "/" for folder simulation
    continuation_token: Option<String>,
    max_keys: i32,
) -> Result<ListObjectsResult>
// { objects: Vec<ObjectInfo>, prefixes: Vec<String>, next_token: Option<String>, truncated: bool }
// ObjectInfo: { key, size, last_modified, etag, content_type, storage_class }

s3_get_object_metadata(
    project_path: String, connection_name: String,
    bucket: String, key: String,
) -> Result<ObjectMetadata>
// { content_type, content_length, last_modified, etag, user_metadata: HashMap, storage_class }

s3_get_object_preview(
    project_path: String, connection_name: String,
    bucket: String, key: String,
    max_bytes: usize,   // e.g. 1MB for text preview
) -> Result<Vec<u8>>   // raw bytes; frontend decides rendering

s3_download_object(
    project_path: String, connection_name: String,
    bucket: String, key: String,
    dest_path: String,
) -> Result<()>   // streams to disk; emits progress events: s3-download-progress-{key}

s3_upload_object(
    project_path: String, connection_name: String,
    bucket: String, key: String,
    src_path: String,
    content_type: Option<String>,
    metadata: Option<HashMap<String, String>>,
) -> Result<()>   // multipart for large files; emits s3-upload-progress-{key}

s3_delete_objects(
    project_path: String, connection_name: String,
    bucket: String, keys: Vec<String>,
) -> Result<u64>   // count deleted

s3_presign_url(
    project_path: String, connection_name: String,
    bucket: String, key: String,
    expires_secs: u64,
) -> Result<String>   // presigned HTTPS URL

s3_get_bucket_policy(
    project_path: String, connection_name: String,
    bucket: String,
) -> Result<String>   // raw JSON policy

s3_put_bucket_policy(
    project_path: String, connection_name: String,
    bucket: String, policy_json: String,
) -> Result<()>

s3_update_object_metadata(
    project_path: String, connection_name: String,
    bucket: String, key: String,
    content_type: String,
    metadata: HashMap<String, String>,
) -> Result<()>   // implemented as copy-object with new metadata
```

### Rust deps to add

```toml
aws-config = { version = "1", features = ["behavior-version-latest"] }
aws-sdk-s3 = { version = "1", features = ["behavior-version-latest"] }
aws-smithy-http = "0.60"
```

The `aws-sdk-s3` client works for all S3-compatible providers by setting a custom endpoint URL
and optionally enabling path-style addressing (`path_style: true` in the connection file).

## Frontend (Svelte)

### New files

```
src/lib/components/workspace/S3Tab.svelte        # bucket browser + object viewer
src/lib/components/panels/S3Panel.svelte         # connection list + bucket list
src/lib/commands/s3.js                           # Tauri command wrappers
```

### S3Panel.svelte (sidebar)

- Connection list with status.
- Expand a connected connection → list buckets.
- Click bucket → `workspace.openTab({ type: 's3-bucket', data: { connection, bucket } })`.
- New / Edit / Delete connection.

### S3Tab.svelte (main browser)

- Breadcrumb bar: connection → bucket → prefix path.
- Toolbar: Upload button, New Folder (creates zero-byte prefix), Refresh, View mode toggle.
- Object list (list or grid view).
- Right-click context menu with all object actions.
- Upload drop zone overlay (shows on drag-enter).

### Upload progress

Each in-flight upload shown as a progress item in a small overlay panel (bottom-right corner,
like VS Code's source control operations). Disappears on completion.

### Preview pane

Opens as a sliding right drawer within the S3Tab. Close button returns to full-width list.

### Object grid view

For image-heavy buckets: thumbnail grid (128×128, `object-fit: cover`).
Thumbnails fetched on demand via presigned URLs (5-minute expiry, cached in memory).
Non-image files: icon grid with filename below.
